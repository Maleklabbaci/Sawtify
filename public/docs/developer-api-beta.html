BETA

Sawtify Developer API

Intègre la synthèse vocale Sawtify dans un chatbot, une boîte vocale, un CRM ou une automatisation.

Conditions

L’accès nécessite un solde strictement supérieur à 1 000 points. La clé API doit rester sur ton serveur, jamais dans le frontend public.

Créer une clé

POST /api/v1/developer/keys
Authorization: Bearer SUPABASE_ACCESS_TOKEN
Content-Type: application/json

{"name":"Mon chatbot"}

Générer un audio WAV

POST /api/v1/developer/tts
X-Sawtify-API-Key: swt_beta_...
Content-Type: application/json

{"text":"Bonjour, votre message est confirmé.","voice_id":"voice_amin"}

La réponse est un fichier audio/wav, mono, 24 kHz, directement utilisable par un serveur vocal.

Réponse JSON

Ajoute "format":"json" pour recevoir audio_base64, mime_type, duration_seconds, points_deducted et remaining_balance.

Voix

voice_amin, voice_yasmin, voice_khalid, voice_maryam, voice_rashid, voice_layla, voice_bilal, voice_nour, voice_faycal.

Erreurs

401 clé invalide · 403 solde inférieur ou égal à 1 000 · 402 solde insuffisant · 429 quota atteint · 503 service temporairement indisponible sans débit.
