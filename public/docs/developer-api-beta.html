Générer une voix

L’endpoint renvoie directement un fichier WAV mono 24 kHz. Ce format est adapté aux lecteurs web, aux bots et à la plupart des solutions de téléphonie.

POST/api/v1/developer/tts
ParamètreTypeDescription
textstringTexte à vocaliser, maximum 5 000 caractères.
voice_idstringVoix Sawtify choisie. Par défaut : voice_amin.
speednumberVitesse, par exemple 1.
pitchnumberHauteur, par exemple 1.
formatstringwav pour un fichier direct ou json pour Base64.
Réponse audio directecURL
curl -X POST https://sawtify.space/api/v1/developer/tts \
  -H "X-Sawtify-API-Key: swt_beta_xxx" \
  -H "Content-Type: application/json" \
  -d '{"text":"Bonjour, votre demande est confirmée.","voice_id":"voice_amin"}' \
  --output reponse.wav
Réponse JSON · pratique pour un chatbotJavaScript
const response = await fetch('https://sawtify.space/api/v1/developer/tts', {
  method: 'POST',
  headers: {
    'X-Sawtify-API-Key': process.env.SAWTIFY_API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    text: 'Bonjour, votre commande est confirmée.',
    voice_id: 'voice_amin',
    format: 'json'
  })
});
const data = await response.json();
const wavBuffer = Buffer.from(data.audio_base64, 'base64');

Où utiliser Sawtify ?

Chatbot et réponse aux messages

Ton chatbot reçoit une question, prépare une réponse puis appelle Sawtify. Le buffer audio retourné peut être envoyé dans WhatsApp, un widget web, Discord ou une application mobile.

Boîte vocale et standard téléphonique

Génère des réponses vocales, messages d’attente, confirmations de rendez-vous ou menus d’accueil. Utilise la sortie WAV puis adapte-la au codec demandé par ton fournisseur téléphonique.

CRM et automatisations

Après une commande, un paiement ou une modification de statut, ton automatisation peut produire un message audio personnalisé et le stocker dans ton système.

Voix et format de sortie

Voix disponibles : voice_amin, voice_yasmin, voice_khalid, voice_maryam, voice_rashid, voice_layla, voice_bilal, voice_nour et voice_faycal.

✓
Format recommandé pour un serveur vocalWAV PCM, mono, 24 000 Hz. Si ton fournisseur exige un autre codec, convertis le fichier côté serveur après réception.

Bonnes pratiques de sécurité

Ne mets jamais ta clé dans React, une application mobile distribuée, GitHub ou un script exécuté dans le navigateur. Utilise une variable serveur comme SAWTIFY_API_KEY, limite les personnes qui peuvent la voir et révoque-la immédiatement si elle fuit. Crée une clé différente pour chaque application ou client.
